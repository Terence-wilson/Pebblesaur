Pebblesaur

Run your Liftosaur workouts from your Pebble watch.

View on GitHub Build & install

Features

  • See your next (or in-progress) workout and switch between exercises
  • Mark sets complete with one click, and undo them
  • Update reps for any set; AMRAP sets ask automatically
  • Log RPE for sets that track it
  • Rest timer using your program's rest times, with a vibration when it ends
  • Finish the workout: it's saved to Liftosaur and progressions run

Setup

  1. In Liftosaur, go to Settings → API Keys → Create API Key (requires Liftosaur premium).
  2. Build and install Pebblesaur on your watch.
  3. In the Pebble phone app, open Pebblesaur's settings and paste the key.

Supported watches

Pebble Time, Time Round, Pebble 2, Time 2 and Pebble 2 Duo. The original Pebble (aplite) isn't supported.
