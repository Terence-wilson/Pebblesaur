## Description (limit 1600 characters)

Run your Liftosaur workout from your wrist.

Pebblesaur connects to Liftosaur's REST API, so progressions, 1RMs and your next workout day update exactly as if you had used the Liftosaur app.

- See your next (or in-progress) workout and switch between exercises
- Mark sets complete with one click, and undo them
- Change reps for any set; AMRAP sets ask for reps automatically
- Log RPE for sets that track it
- Rest timer using your program's rest times. It vibrates when rest is over, even if you closed the app
- Finish the workout from the watch: it is saved to Liftosaur and the next day is loaded

REQUIREMENTS
- A Liftosaur account with a premium subscription (needed for API access)
- A Liftosaur API key: in Liftosaur go to Settings > API Keys > Create API Key, then paste it into Pebblesaur's settings in the Pebble phone app

Supports Pebble Time, Time Round, Pebble 2, Time 2 and Pebble 2 Duo. The original Pebble is not supported.
