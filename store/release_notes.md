Initial release (v1.0.0)

- See your next or in-progress Liftosaur workout and switch between exercises
- Mark sets complete with one click, and undo them
- Change reps for any set; AMRAP sets ask for reps automatically
- Log RPE for sets that track it
- Rest timer using your program's rest times, with a vibration when rest is over, even if you have closed the app
- Finish the workout from the watch: it is saved to Liftosaur and the next day is loaded

Setup: create an API key in Liftosaur (Settings > API Keys, premium required) and paste it into Pebblesaur's settings in the Pebble phone app.

Supports Pebble Time, Time Round, Pebble 2, Time 2 and Pebble 2 Duo.
